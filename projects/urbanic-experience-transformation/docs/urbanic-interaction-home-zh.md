# 首页与导航｜交互设计说明

根据项目设计稿与项目复盘整理。此说明侧重体验目标与关键判断，具体交互行为以原始原型为准。

## 体验目标
首页同时承担品牌认知、内容浏览与商品发现。此次升级希望让用户先感受到 Urbanic 的品牌与时尚内容，再顺畅进入商品浏览；营销信息服务于购买决策，避免占据过多注意力。

## 典型路径
进入首页 → 浏览品牌内容与商品入口 → 通过导航或页面内容进入商品浏览 → 进一步查看感兴趣的商品。

## 关键设计判断
- 品牌与商品优先：通过首屏影像、品牌字体、内容布局和商品呈现建立新的品牌认知。
- 入口清晰：导航、内容与商品入口形成可辨识的信息层级，帮助用户理解下一步可以做什么。
- 营销适度：结合商业价值与品牌定位，调整营销入口的数量、优先级和视觉权重。
- 多端一致：App、移动网页与桌面网页共享品牌表达和内容优先级，同时适配不同设备的布局与入口。

## 多端呈现
项目展示中的桌面首页以横向空间呈现品牌影像与内容；移动端首页根据屏幕宽度组织首屏和导航。用户在不同设备上看到的是同一品牌，但布局方式会随设备调整。

## 状态与反馈
设计稿可见首页和导航入口。菜单展开与关闭、返回与滚动、入口的加载和异常反馈等具体行为，需以原始交互原型或实际产品核实；本说明不预设当时的实现方式。

## 设计取舍
原有首页需要同时承载品牌、商品、活动和营销。项目的判断是降低部分促销工具的视觉主导，让品牌与商品更容易被理解，同时保留实际有价值的商业入口。
